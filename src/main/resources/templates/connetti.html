Gemini CLI

    

        The official Google CLI (gemini) supports MCP servers via HTTP.
        Edit (or create) ~/.gemini/settings.json and add
        the mcpServers section:
    

    

        

        
    


    
Don't have Gemini CLI yet?

    

        npm install -g @google/gemini-cli
        
    


    
Start and verify

    

        gemini
        
    


    

        Gemini CLI automatically loads ~/.gemini/settings.json on startup.
        Type /tools in the session to see available MCP tools.
        The timeout field is in milliseconds — increase it if the APIs are slow.

Global configuration (all projects)

    

        Open Ctrl+Shift+P → Open User Settings (JSON) and add
        the same structure under the "mcp.servers" key.
    


    
Install required extensions (if you don't have them)

    

        code --install-extension GitHub.copilot
        
    


    

        Reload the VS Code window (Ctrl+Shift+P → Reload Window) after
        creating the file. In Copilot Chat's agent mode, mcp-forge tools will appear
        automatically as available tools.
    







    
Cursor

    

        Cursor supports MCP servers natively. For a global configuration
        (valid in all projects) create or edit ~/.cursor/mcp.json.
        For a project-local configuration use .cursor/mcp.json
        in the repo root:
    

    

        

        
    


    
Enable tools in agent mode

    

        After saving the file, restart Cursor. Open the Composer with
        Ctrl+I, switch to Agent (not normal Chat)
        and click the tools icon: you'll see the mcp-forge tools listed and selectable.
    


    

        Cursor uses the "url" key for HTTP MCP servers —
        no need to specify transport because it auto-detects from the URL.
        If you have multiple MCP servers, add them all under "mcpServers"
        as separate keys.

        Supports MCP servers via TOML. Add this block in
        ~/.codex/config.toml (create it if it doesn't exist):
    

    

        

        
    


    
Don't have Codex CLI yet?

    

        npm install -g @openai/codex
        
    


    
Set the API key and start

    

        export OPENAI_API_KEY="sk-..." && codex
        
    


    

        Codex CLI loads MCP servers defined in TOML at session startup.
        You can have multiple [[mcp_servers]] blocks for different servers.
        Type your request in natural language — Codex will autonomously decide which tools to call.
