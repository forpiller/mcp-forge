How to activate local chat

Chat uses Ollama (hermes3) as the local LLM — no cost, no account.

  1. Install Ollama
    macOS: brew install ollama
    Or download the installer from ollama.com
  2. Start the Ollama server (in a separate terminal, keep it open):
    ollama serve
  3. Download the Hermes 3 model (about 4.7 GB, one-time):
    ollama pull hermes3
  4. Reload this page — the chat will activate automatically.
Note: local chat requires about 5–8 GB of free RAM and may be slow on less powerful machines. For a better experience — with no hardware requirements — connect Claude, Gemini or Cursor directly to mcp-forge via the Connect page: just copy a command, then use your favorite AI with all the tools ready.
